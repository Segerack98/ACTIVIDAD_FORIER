# Simulación y análisis de señales con Fourier

## Descripción
Proyecto de la Actividad Formativa 2 desarrollado en Python.

Analiza una señal senoidal de 5 Hz, un pulso rectangular
y una función escalón mediante la Transformada Rápida
de Fourier (FFT).

También estudia las propiedades de linealidad,
desplazamiento temporal circular y escalamiento temporal.

## Herramientas
- Python
- NumPy
- Matplotlib
- Visual Studio Code

## Archivos
- Main.py: genera las señales y sus espectros de magnitud y fase.
- propiedades_fourier.py: analiza las propiedades de Fourier.
- graficas/: contiene las gráficas de los resultados.

## Instalación
Ejecutar en la terminal:

    python -m pip install numpy matplotlib

## Ejecución
Para generar las señales y sus transformadas:

    python Main.py

Para estudiar las propiedades:

    python propiedades_fourier.py
